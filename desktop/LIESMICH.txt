SONDRA FÜR WINDOWS

Starten
  Doppelklick auf Sondra.exe. Ein Konsolenfenster öffnet sich, danach der
  Browser mit Sondra. Solange das Fenster offen ist, läuft Sondra; es zu
  schliessen beendet Sondra.

Keine Installation
  Nichts wird installiert, keine Administratorrechte nötig. Der ganze Ordner
  kann auf einem USB-Stick liegen. Zum Entfernen den Ordner löschen.

Was im Ordner liegt
  Sondra.exe   der lokale Server (eine Node.js-Laufzeit mit Sondra darin)
  app\         die Oberfläche — muss neben Sondra.exe liegen
  lizenzen\    Lizenztexte der enthaltenen Fremdsoftware
  LIZENZ.txt   Lizenz, Haftungsausschluss, Hinweis zum lokalen Betrieb

Windows-SmartScreen
  Sondra.exe ist nicht signiert. Beim ersten Start kann Windows „Der Computer
  wurde durch Windows geschützt“ zeigen: „Weitere Informationen“ und dann
  „Trotzdem ausführen“.

Anderer Port
  Sondra nimmt Port 4199; ist der belegt, einen freien. Die Adresse steht im
  Konsolenfenster.

Eigener Extraktionsdienst (optional)
  Wie auf der Website unter „Herunterladen“ → „Optionen“. Alternativ vor dem
  Start die Umgebungsvariablen SONDRA_PROVIDER_URL und SONDRA_PROVIDER_KEY
  setzen.
